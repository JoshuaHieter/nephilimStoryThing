# Opening this vault in Obsidian

1. Install Obsidian (https://obsidian.md) — free for personal use.
2. **Open folder as vault** → select this `Vault` folder.
3. (Optional) Settings → **Core plugins** → enable **Templates**, then set the
   template folder to `Templates`. You can then insert a template into any new
   note with the template command.

Start at [[index]].

## How this vault is organized

- `Characters/`, `Factions/`, `Locations/`, `Lore & History/`, `Rules & Mechanics/`, `Sessions/`
  each hold notes, with an `_index.md` map-of-content listing what's inside.
- `Templates/` holds reusable note skeletons.
- Notes link to each other with `[[wiki links]]`; use the graph view to see how
  the setting connects.

This structure is just a starting point — rename, merge, or add folders freely.
